# Coding Rules

## Frontend Naming and Exposure

1. Do not expose scenario switching links or manager hints on candidate-facing pages.
2. Do not show labels like "Scenario C" in candidate-facing UI text.
3. Use neutral naming in UI (for example: "Booking Flow", "Site A", "Site B").
4. Internal route/mode identifiers (for example: scenarioA-E) may remain for implementation, but must not be displayed to candidates.

## Scope

These rules apply to all candidate-facing frontend pages under public/.
